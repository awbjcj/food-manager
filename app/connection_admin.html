Setup checklist

  1. Create your provider's bot or business app.
  2. Add its credentials here. They are encrypted and cannot be read back.
  3. Use the connection's setup instructions to configure webhooks or install Slack.
  4. Validate credentials, then send a direct message from the bootstrap account.
  5. Refresh status and enable the connection. Send start to begin.
  6. Send reminders on to select that connection for your daily digest.

For WhatsApp, use Meta's official Cloud API and an eligible business phone number. Outside the customer service window, daily reminders require an approved template with one body parameter for the number of items due.

To share an existing account, send link from its connection and follow the instructions. Installation alone never grants pantry access.
