# Recipe Engine Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `/cook` return real, linked, nutrition-backed recipes via a tiered `RecipeSource` chain (Spoonacular → TheMealDB → existing LLM pipeline), add a purpose intake axis + expandable cuisines, and add a More/Adjust regenerate loop over real paginated results.

**Architecture:** Introduce one deep seam — `app/recipe_source.py` — that hides every provider difference behind `available()` + `async search(criteria) -> (recipes, cost)`. `cook_service.run_cook` keeps the selection LLM (pantry → subset) and the `blended_score` ranking, but its recipe+nutrition stages become just another adapter (`LlmRecipeSource`) at the bottom of the chain. Criteria-building and Spoonacular param/response mapping are pure functions whose interface is the test surface.

**Tech Stack:** Python 3, SQLModel/SQLAlchemy, Alembic, aiogram, httpx, pytest, uv. Spec: `docs/superpowers/specs/2026-06-10-v4.9-recipe-engine-design.md`.

## Architecture notes (read once)

- **One seam, three adapters.** `RecipeSource` is a Protocol; `SpoonacularSource`, `TheMealDbSource`, `LlmRecipeSource` are adapters; `ChainedRecipeSource` orders them. Deletion test: remove the module and provider quirks smear back across `cook_service`. Keep them concentrated.
- **HTTP is injected.** Adapters take an injected async HTTP client (httpx-compatible). Tests pass a fake client returning canned JSON — no network, deterministic. Mirrors how LLM clients are injected today.
- **Pure mappers are the test surface.** `build_criteria(...)`, `spoonacular_params(criteria)`, and `map_spoonacular(json)` are pure — unit-tested directly. The async adapter just glues HTTP + pure mappers.
- **Surgical.** `run_cook` keeps selection + ranking; only the recipe/nutrition *source* changes. The existing recipe/nutrition LLM clients are reused verbatim inside `LlmRecipeSource`. The intake-round mechanism (`build_cook_round_keyboard`, `cookpick:`) is extended, not rebuilt.
- **Robustness first.** A missing key / quota error / network failure makes an adapter yield nothing; the chain advances. The LLM tail guarantees `/cook` always answers.

```python
from __future__ import annotations

import logging
from typing import Optional, Protocol

from app.cook_models import Purpose, RecipeCriteria
from app.profile_service import FoodProfile

log = logging.getLogger(__name__)

MEAL_TYPE_TO_SPOON = {
    "Dinner": "main course",
    "Lunch": "main course",
    "Breakfast": "breakfast",
    "Dessert": "dessert",
    "Snack": "snack",
}
_QUICK_MINUTES = 30
_PURPOSE_SORT = {
    Purpose.USE_IT_UP: "max-used-ingredients",
    Purpose.HEALTHY: "healthiness",
    Purpose.COMFORT: "popularity",
}


def build_criteria(
    *, include_ingredients: list[str], meal_type: Optional[str], cuisine: Optional[str],
    purpose: Purpose, profile: FoodProfile, offset: int, number: int = 6,
) -> RecipeCriteria:
    meal = None if (meal_type in (None, "Surprise me")) else meal_type
    cui = None if (cuisine in (None, "Surprise me", "Any")) else cuisine
    max_ready = _QUICK_MINUTES if purpose == Purpose.QUICK else profile.max_cook_minutes
    diet = None if profile.diet in (None, "", "none", "omnivore") else profile.diet
    return RecipeCriteria(
        include_ingredients=list(include_ingredients),
        purpose=purpose,
        meal_type=meal,
        cuisine=cui,
        diet=diet,
        intolerances=list(profile.exclusions),
        exclude_ingredients=list(profile.exclusions),
        max_ready_minutes=max_ready,
        number=number,
        offset=offset,
    )


def spoonacular_params(criteria: RecipeCriteria, *, api_key: str) -> dict:
    params: dict = {
        "apiKey": api_key,
        "number": criteria.number,
        "offset": criteria.offset,
        "addRecipeInformation": "true",
        "addRecipeNutrition": "true",
        "fillIngredients": "true",
    }
    if criteria.include_ingredients:
        params["includeIngredients"] = ",".join(criteria.include_ingredients)
    if criteria.meal_type:
        params["type"] = MEAL_TYPE_TO_SPOON.get(criteria.meal_type, "main course")
    if criteria.cuisine:
        params["cuisine"] = criteria.cuisine
    if criteria.diet:
        params["diet"] = criteria.diet
    if criteria.intolerances:
        params["intolerances"] = ",".join(criteria.intolerances)
    if criteria.exclude_ingredients:
        params["excludeIngredients"] = ",".join(criteria.exclude_ingredients)
    if criteria.max_ready_minutes:
        params["maxReadyTime"] = criteria.max_ready_minutes
    sort = _PURPOSE_SORT.get(criteria.purpose)
    if sort:
        params["sort"] = sort
    return params
```

```python
def _nutrition_rationale(raw: dict) -> str:
    nutrients = (raw.get("nutrition") or {}).get("nutrients") or []
    wanted = {"Calories": None, "Protein": None, "Fat": None, "Carbohydrates": None}
    for n in nutrients:
        if n.get("name") in wanted:
            wanted[n["name"]] = f"{round(n.get('amount', 0))}{n.get('unit', '')}"
    parts = [f"{k} {v}" for k, v in wanted.items() if v]
    return ", ".join(parts) if parts else "nutrition from recipe database"


def map_spoonacular(payload: dict) -> list[SourcedRecipe]:
    out: list[SourcedRecipe] = []
    for raw in payload.get("results", []):
        ingredients = [
            RecipeIngredient(name=i.get("name", ""), qty=i.get("amount"), unit=(i.get("unit") or None))
            for i in (raw.get("extendedIngredients") or [])
            if i.get("name")
        ]
        steps = [
            s.get("step", "")
            for block in (raw.get("analyzedInstructions") or [])
            for s in (block.get("steps") or [])
        ]
        method = " ".join(steps).strip()[:500] or "See source for full method."
        cuisines = raw.get("cuisines") or []
        minutes = raw.get("readyInMinutes")
        recipe = RecipeCandidate(
            title=raw.get("title", "Untitled"),
            cuisine=(cuisines[0] if cuisines else "various"),
            source_url=raw.get("sourceUrl"),
            ingredients=ingredients or [RecipeIngredient(name="(see source)")],
            method_gist=method,
            deliciousness=max(0.0, min(1.0, (
                50.0 if raw.get("spoonacularScore") is None else raw["spoonacularScore"]
            ) / 100.0)),
        )
        nutrition = NutritionScore(
            health_score=int(50 if raw.get("healthScore") is None else raw["healthScore"]),
            effort=_effort_for(minutes),
            est_minutes=int(minutes) if minutes else 30,
            rationale=_nutrition_rationale(raw),
        )
        raw_id = raw.get("id")
        out.append(SourcedRecipe(
            recipe=recipe,
            nutrition=nutrition,
            external_id=None if raw_id is None else str(raw_id),
        ))
    return out
```
