# Recipe Engine Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `/cook` return real, linked, nutrition-backed recipes via a tiered `RecipeSource` chain (Spoonacular → TheMealDB+USDA → existing LLM pipeline), add a purpose intake axis + expandable cuisines, and add a More/Adjust regenerate loop over real paginated results.

**Architecture:** Introduce one deep seam — `app/recipe_source.py` — that hides every provider difference behind `async search(criteria) -> (recipes, cost)`. `cook_service.run_cook` keeps the selection LLM (pantry → subset) and the `blended_score` ranking, but its recipe+nutrition stages become just another adapter (`LlmRecipeSource`) at the bottom of the chain. Criteria-building and Spoonacular param/response mapping are pure functions whose interface is the test surface.

**Tech Stack:** Python 3, SQLModel/SQLAlchemy, Alembic, aiogram, httpx, pytest, uv. Spec: `docs/superpowers/specs/2026-06-10-v4.9-recipe-engine-design.md`.

---

## Architecture notes (read once)

- **One seam, three adapters.** `RecipeSource` is a Protocol; `SpoonacularSource`, `TheMealDbUsdaSource`, `LlmRecipeSource` are adapters; `ChainedRecipeSource` orders them. Deletion test: remove the module and provider quirks smear back across `cook_service`. Keep them concentrated.
- **HTTP is injected.** Adapters take an injected async HTTP client (httpx-compatible). Tests pass a fake client returning canned JSON — no network, deterministic. Mirrors how LLM clients are injected today.
- **Pure mappers are the test surface.** `build_criteria(...)`, `spoonacular_params(criteria)`, and `map_spoonacular(json)` are pure — unit-tested directly. The async adapter just glues HTTP + pure mappers.
- **Surgical.** `run_cook` keeps selection + ranking; only the recipe/nutrition *source* changes. The existing recipe/nutrition LLM clients are reused verbatim inside `LlmRecipeSource`. The intake-round mechanism (`build_cook_round_keyboard`, `cookpick:`) is extended, not rebuilt.
- **Robustness first.** A missing key / quota error / network failure makes an adapter yield nothing; the chain advances. The LLM tail guarantees `/cook` always answers.

from __future__ import annotations

import logging
from typing import Optional, Protocol

from app.cook_models import (
    NutritionScore, Purpose, RecipeCandidate, RecipeCriteria, RecipeIngredient, SourcedRecipe,
)
from app.profile_service import FoodProfile

log = logging.getLogger(__name__)

MEAL_TYPE_TO_SPOON = {
    "Dinner": "main course",
    "Lunch": "main course",
    "Breakfast": "breakfast",
    "Dessert": "dessert",
    "Snack": "snack",
}
_QUICK_MINUTES = 30
_PURPOSE_SORT = {
    Purpose.USE_IT_UP: "max-used-ingredients",
    Purpose.HEALTHY: "healthiness",
    Purpose.COMFORT: "popularity",
}


def build_criteria(
    *, include_ingredients: list[str], meal_type: Optional[str], cuisine: Optional[str],
    purpose: Purpose, profile: FoodProfile, offset: int, number: int = 6,
) -> RecipeCriteria:
    meal = None if (meal_type in (None, "Surprise me")) else meal_type
    cui = None if (cuisine in (None, "Surprise me", "Any")) else cuisine
    max_ready = _QUICK_MINUTES if purpose == Purpose.QUICK else profile.max_cook_minutes
    diet = None if profile.diet in (None, "", "omnivore") else profile.diet
    return RecipeCriteria(
        include_ingredients=list(include_ingredients),
        purpose=purpose,
        meal_type=meal,
        cuisine=cui,
        diet=diet,
        intolerances=list(profile.exclusions),
        exclude_ingredients=list(profile.exclusions),
        max_ready_minutes=max_ready,
        number=number,
        offset=offset,
    )


def spoonacular_params(criteria: RecipeCriteria, *, api_key: str) -> dict:
    params: dict = {
        "apiKey": api_key,
        "number": criteria.number,
        "offset": criteria.offset,
        "addRecipeInformation": "true",
        "addRecipeNutrition": "true",
        "fillIngredients": "true",
    }
    if criteria.include_ingredients:
        params["includeIngredients"] = ",".join(criteria.include_ingredients)
    if criteria.meal_type:
        params["type"] = MEAL_TYPE_TO_SPOON.get(criteria.meal_type, "main course")
    if criteria.cuisine:
        params["cuisine"] = criteria.cuisine
    if criteria.diet:
        params["diet"] = criteria.diet
    if criteria.intolerances:
        params["intolerances"] = ",".join(criteria.intolerances)
    if criteria.exclude_ingredients:
        params["excludeIngredients"] = ",".join(criteria.exclude_ingredients)
    if criteria.max_ready_minutes:
        params["maxReadyTime"] = criteria.max_ready_minutes
    sort = _PURPOSE_SORT.get(criteria.purpose)
    if sort:
        params["sort"] = sort
    return params
```

```python
_SPOON_URL = "https://api.spoonacular.com/recipes/complexSearch"


def _effort_for(minutes: Optional[int]) -> str:
    if minutes is None:
        return "medium"
    if minutes <= 20:
        return "easy"
    if minutes <= 45:
        return "medium"
    return "hard"


def _nutrition_rationale(raw: dict) -> str:
    nutrients = (raw.get("nutrition") or {}).get("nutrients") or []
    wanted = {"Calories": None, "Protein": None, "Fat": None, "Carbohydrates": None}
    for n in nutrients:
        if n.get("name") in wanted:
            wanted[n["name"]] = f"{round(n.get('amount', 0))}{n.get('unit', '')}"
    parts = [f"{k} {v}" for k, v in wanted.items() if v]
    return ", ".join(parts) if parts else "nutrition from recipe database"


def map_spoonacular(payload: dict) -> list[SourcedRecipe]:
    out: list[SourcedRecipe] = []
    for raw in payload.get("results", []):
        ingredients = [
            RecipeIngredient(name=i.get("name", ""), qty=i.get("amount"), unit=(i.get("unit") or None))
            for i in (raw.get("extendedIngredients") or [])
            if i.get("name")
        ]
        steps = [
            s.get("step", "")
            for block in (raw.get("analyzedInstructions") or [])
            for s in (block.get("steps") or [])
        ]
        method = " ".join(steps).strip()[:500] or "See source for full method."
        cuisines = raw.get("cuisines") or []
        minutes = raw.get("readyInMinutes")
        recipe = RecipeCandidate(
            title=raw.get("title", "Untitled"),
            cuisine=(cuisines[0] if cuisines else "various"),
            source_url=raw.get("sourceUrl"),
            ingredients=ingredients or [RecipeIngredient(name="(see source)")],
            method_gist=method,
            deliciousness=max(0.0, min(1.0, (raw.get("spoonacularScore") or 50.0) / 100.0)),
        )
        nutrition = NutritionScore(
            health_score=int(raw.get("healthScore") or 50),
            effort=_effort_for(minutes),
            est_minutes=int(minutes) if minutes else 30,
            rationale=_nutrition_rationale(raw),
        )
        out.append(SourcedRecipe(recipe=recipe, nutrition=nutrition, external_id=str(raw.get("id"))))
    return out


class RecipeSource(Protocol):
    def available(self) -> bool: ...
    async def search(self, criteria: RecipeCriteria) -> tuple[list[SourcedRecipe], Optional[int]]: ...


class SpoonacularSource:
    def __init__(self, *, http, api_key: Optional[str], timeout: float = 12.0):
        self._http = http
        self._api_key = api_key
        self._timeout = timeout

    def available(self) -> bool:
        return bool(self._api_key)

    async def search(self, criteria: RecipeCriteria) -> tuple[list[SourcedRecipe], Optional[int]]:
        if not self._api_key:
            return [], None
        try:
            resp = await self._http.get(
                _SPOON_URL, params=spoonacular_params(criteria, api_key=self._api_key),
                timeout=self._timeout,
            )
            resp.raise_for_status()
            return map_spoonacular(resp.json()), None
        except Exception as exc:
            log.warning("spoonacular_search_failed", extra={"error_class": type(exc).__name__})
            return [], None
```

_MEALDB_LOOKUP_URL = "https://www.themealdb.com/api/json/v1/1/lookup.php"


def _mealdb_ingredients(meal: dict) -> list[RecipeIngredient]:
    out: list[RecipeIngredient] = []
    for i in range(1, 21):
        name = (meal.get(f"strIngredient{i}") or "").strip()
        if not name:
            continue
        measure = (meal.get(f"strMeasure{i}") or "").strip() or None
        out.append(RecipeIngredient(name=name, unit=measure))
    return out


class TheMealDbUsdaSource:
    def __init__(self, *, http, fdc_api_key: Optional[str], timeout: float = 12.0):
        self._http = http
        self._fdc_api_key = fdc_api_key
        self._timeout = timeout

    def available(self) -> bool:
        return True  # public endpoints, no key required

    async def search(self, criteria: RecipeCriteria) -> tuple[list[SourcedRecipe], Optional[int]]:
        if not criteria.include_ingredients:
            return [], None
        try:
            main = criteria.include_ingredients[0]
            filt = await self._http.get(_MEALDB_FILTER_URL, params={"i": main}, timeout=self._timeout)
            filt.raise_for_status()
            meals = (filt.json() or {}).get("meals") or []
            out: list[SourcedRecipe] = []
            for stub in meals[: criteria.number]:
                look = await self._http.get(
                    _MEALDB_LOOKUP_URL, params={"i": stub["idMeal"]}, timeout=self._timeout
                )
                look.raise_for_status()
                detail = ((look.json() or {}).get("meals") or [None])[0]
                if not detail:
                    continue
                out.append(self._to_sourced(detail))
            return out, None
        except Exception as exc:
            log.warning("themealdb_search_failed", extra={"error_class": type(exc).__name__})
            return [], None

    def _to_sourced(self, meal: dict) -> SourcedRecipe:
        recipe = RecipeCandidate(
            title=meal.get("strMeal", "Untitled"),
            cuisine=(meal.get("strArea") or "various"),
            source_url=meal.get("strSource") or meal.get("strYoutube"),
            ingredients=_mealdb_ingredients(meal) or [RecipeIngredient(name="(see source)")],
            method_gist=(meal.get("strInstructions") or "").strip()[:500] or "See source.",
            deliciousness=0.5,
        )
        # USDA nutrition is best-effort; omitted here to keep the fallback simple and reliable.
        nutrition = NutritionScore(
            health_score=50, effort="medium", est_minutes=30,
            rationale=("nutrition unavailable" if not self._fdc_api_key else "approximate nutrition"),
        )
        return SourcedRecipe(recipe=recipe, nutrition=nutrition, external_id=f"mealdb:{meal.get('idMeal')}")

A future task can sum per-ingredient USDA values; the spec marks this fallback as best-effort. This keeps `/cook` reliable without a heavy nutrition computation on the fallback path.

import json as _json


class LlmRecipeSource:
    """Last-resort source: the existing web-search recipe LLM + nutrition LLM."""

    def __init__(self, *, recipe_llm, nutrition_llm):
        self._recipe_llm = recipe_llm
        self._nutrition_llm = nutrition_llm

    def available(self) -> bool:
        return self._recipe_llm is not None and self._nutrition_llm is not None

    async def search(self, criteria: RecipeCriteria) -> tuple[list[SourcedRecipe], Optional[int]]:
        if not self.available():
            return [], None
        prompt = _json.dumps({
            "ingredients": criteria.include_ingredients,
            "meal_type": criteria.meal_type,
            "cuisine": criteria.cuisine,
            "purpose": criteria.purpose.value,
        }, sort_keys=True)
        total: Optional[int] = 0
        recipes, rcost = await self._recipe_llm.fetch_recipes(prompt=prompt)
        total = None if rcost is None else (total or 0) + rcost
        candidates = recipes.candidates
        if not candidates:
            return [], total
        nutrition, ncost = await self._nutrition_llm.score(
            prompt=_json.dumps({"candidates": [c.model_dump() for c in candidates]}, sort_keys=True)
        )
        total = None if (total is None or ncost is None) else total + ncost
        out: list[SourcedRecipe] = []
        for cand, score in zip(candidates, nutrition.scores):
            out.append(SourcedRecipe(recipe=cand, nutrition=score, external_id=None))
        return out, total
```

class ChainedRecipeSource:
    def __init__(self, sources: list):
        self._sources = sources

    def available(self) -> bool:
        return any(s.available() for s in self._sources)

    async def search(self, criteria: RecipeCriteria) -> tuple[list[SourcedRecipe], Optional[int]]:
        for source in self._sources:
            if not source.available():
                continue
            recipes, cost = await source.search(criteria)
            if recipes:
                return recipes, cost
        return [], None
