# v5.4 Waste & Consumption Analytics Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Record *when* pantry items reach a terminal state (`resolved_on`) and expose an on-demand `/stats week|month|all` waste report (eaten vs tossed, expired-vs-early split, top-tossed foods, per-category counts, previous-period delta, one deterministic nudge line) — while the bare `/stats` ops report stays byte-identical.

**Architecture:** One additive nullable column on `PantryItem`; a new pure-query module `app/stats_service.py` (dataclasses + aggregation + nudge rule table, no LLM); one new parser in `app/commands.py`; one new sync renderer in `app/renderer.py` with `waste.*` i18n keys; arg-dispatch inside the existing `handle_stats` (bare → old ops report unchanged, window token → new report).

**Tech Stack:** SQLModel/SQLAlchemy + Alembic (SQLite), aiogram 3, pytest, uv.

**Spec:** `docs/superpowers/specs/2026-07-09-v5.4-waste-analytics-design.md` (amended 2026-07-09: split-by-argument — bare `/stats` keeps the shipped ops report).

## Global Constraints

- **Explicit `today: date`** — no `datetime.now()` inside service/render logic; callers pass time in.
- **Session injection** — every service function takes `session: Session` first.
- **English stays byte-identical** — bare `/stats` output, all existing renderer strings, and every existing test must be untouched. New i18n keys need all four langs (`en|zh|fr|es`) with placeholder parity (enforced by `tests/test_i18n.py`).
- **Two-phase render** — renderers are pure/sync with `lang="en"` + pre-resolved `names` mapping; the handler does async translation first.
- **DB stores canonical English** — `normalized_name` is the analytics key; translation is render-time only.
- **`removed` status is excluded from waste analytics** (it means "mis-scan", not a consumption outcome) — but `mark_removed` still stamps `resolved_on` per the spec.
- **No backfill** — pre-v5.4 terminal rows keep `resolved_on = NULL`; they count in `all`, are excluded from `week`/`month`, and trigger one honest footnote.
- **No LLM, no push, no money stats, no charts** (spec §6).
- Test command: `uv run pytest -q` (single file: `uv run pytest tests/<file>.py -q`).

```python
from __future__ import annotations

from dataclasses import dataclass
from datetime import date, timedelta
from typing import Literal, Optional

from sqlmodel import Session, col, select

from app.models import PantryItem

StatsWindow = Literal["week", "month", "all"]

WINDOW_DAYS: dict[str, int] = {"week": 7, "month": 30}


@dataclass(frozen=True)
class TossedFood:
    name: str  # normalized_name (canonical English; translated at render time)
    count: int
    expired: int  # resolved after expires_on
    early: int    # resolved on/before expires_on


@dataclass(frozen=True)
class WindowStats:
    eaten: int
    tossed: int
    tossed_expired: int
    tossed_early: int
    top_tossed: list[TossedFood]              # top 3 by count desc, name asc
    by_category: list[tuple[str, int, int]]   # (category, eaten, tossed), category asc

    @property
    def waste_rate(self) -> Optional[float]:
        total = self.eaten + self.tossed
        return self.tossed * 100.0 / total if total else None


@dataclass(frozen=True)
class WasteStats:
    window: StatsWindow
    current: WindowStats
    previous: Optional[WindowStats]  # None for "all"
    window_truncated: bool


def _resolved_expired(item: PantryItem) -> bool:
    return item.resolved_on is not None and item.resolved_on > item.expires_on


def _resolved_early(item: PantryItem) -> bool:
    return item.resolved_on is not None and item.resolved_on <= item.expires_on


def _aggregate(rows: list[PantryItem]) -> WindowStats:
    tossed_rows = [r for r in rows if r.status == "tossed"]
    by_food: dict[str, list[PantryItem]] = {}
    for row in tossed_rows:
        by_food.setdefault(row.normalized_name, []).append(row)
    foods = sorted(
        (
            TossedFood(
                name=name,
                count=len(group),
                expired=sum(1 for r in group if _resolved_expired(r)),
                early=sum(1 for r in group if _resolved_early(r)),
            )
            for name, group in by_food.items()
        ),
        key=lambda f: (-f.count, f.name),
    )
    categories: dict[str, list[int]] = {}
    for row in rows:
        pair = categories.setdefault(row.category or "other", [0, 0])
        pair[0 if row.status == "eaten" else 1] += 1
    return WindowStats(
        eaten=sum(1 for r in rows if r.status == "eaten"),
        tossed=len(tossed_rows),
        tossed_expired=sum(1 for r in tossed_rows if _resolved_expired(r)),
        tossed_early=sum(1 for r in tossed_rows if _resolved_early(r)),
        top_tossed=foods[:3],
        by_category=sorted((name, c[0], c[1]) for name, c in categories.items()),
    )


def waste_stats(
    session: Session, *, household_id: int, window: StatsWindow, today: date
) -> WasteStats:
    rows = list(
        session.exec(
            select(PantryItem).where(
                PantryItem.household_id == household_id,
                col(PantryItem.status).in_(("eaten", "tossed")),
            )
        ).all()
    )
    if window == "all":
        return WasteStats("all", _aggregate(rows), None, window_truncated=False)
    days = WINDOW_DAYS[window]
    since = today - timedelta(days=days)
    prev_since = since - timedelta(days=days)
    dated = [r for r in rows if r.resolved_on is not None]
    current = _aggregate([r for r in dated if since < r.resolved_on <= today])
    previous = _aggregate([r for r in dated if prev_since < r.resolved_on <= since])
    return WasteStats(
        window,
        current,
        previous,
        window_truncated=any(r.resolved_on is None for r in rows),
    )
```

**Files:**

**Interfaces:**
- Consumes: `WasteStats` / `WindowStats` / `TossedFood` from Task 2.
- Produces: `Nudge(code: Literal["freeze", "buy_less", "improved"], food: Optional[str] = None)` and `pick_nudge(stats: WasteStats) -> Optional[Nudge]`. First match wins, per spec §4: (1) top-tossed food mostly expired → `freeze`; (2) top-tossed food mostly early → `buy_less`; (3) waste rate improved vs previous → `improved`; (4) `None`. "Mostly" = strict majority; an expired/early tie on the top food falls through to rule 3.

NudgeCode = Literal["freeze", "buy_less", "improved"]


@dataclass(frozen=True)
class Nudge:
    code: NudgeCode
    food: Optional[str] = None  # normalized_name; set for freeze/buy_less


def pick_nudge(stats: WasteStats) -> Optional[Nudge]:
    """Fixed rule table over the current window, first match wins (spec §4)."""
    top = stats.current.top_tossed[0] if stats.current.top_tossed else None
    if top is not None and top.expired > top.early:
        return Nudge(code="freeze", food=top.name)
    if top is not None and top.early > top.expired:
        return Nudge(code="buy_less", food=top.name)
    current_rate = stats.current.waste_rate
    previous_rate = stats.previous.waste_rate if stats.previous else None
    if current_rate is not None and previous_rate is not None and current_rate < previous_rate:
        return Nudge(code="improved")
    return None

def parse_stats_arg(args: Sequence[str]) -> Optional[StatsWindow]:
    """``/stats`` argument. No args -> None (the classic 30-day ops report);
    a window token selects the waste analytics report."""
    if not args:
        return None
    token = args[0].lower()
    if len(args) == 1 and token in ("week", "month", "all"):
        return cast(StatsWindow, token)
    raise CommandError("usage: /stats [week|month|all]")

```python
def _category_label(category: str, lang: str) -> str:
    key = f"category.{category}"
    return t(key, lang) if key in MESSAGES else category


def render_waste_stats(
    ws: WasteStats,
    nudge: Optional[Nudge] = None,
    *,
    lang: str = "en",
    names: Optional[Mapping[str, str]] = None,
) -> str:
    resolved = names or {}

    def display(name: str) -> str:
        return resolved.get(name, name)

    current = ws.current
    lines = [t(f"waste.header.{ws.window}", lang)]
    if current.eaten + current.tossed == 0:
        lines.append(t("waste.empty", lang))
    else:
        lines.append(t("waste.eaten", lang, eaten=current.eaten))
        lines.append(t(
            "waste.tossed", lang,
            tossed=current.tossed,
            expired=current.tossed_expired,
            early=current.tossed_early,
        ))
        rate = current.waste_rate
        if rate is not None:
            lines.append(t("stats.waste_rate", lang, waste_rate=f"{rate:.1f}%"))
            previous_rate = ws.previous.waste_rate if ws.previous else None
            if previous_rate is not None:
                lines.append(t("waste.delta", lang, delta=f"{rate - previous_rate:+.1f}"))
        if current.top_tossed:
            lines.append(t("waste.top.header", lang))
            for food in current.top_tossed:
                lines.append(t("waste.top.item", lang, name=display(food.name), count=food.count))
        if current.by_category:
            lines.append(t("waste.category.header", lang))
            for category, eaten, tossed in current.by_category:
                lines.append(t(
                    "waste.category.item", lang,
                    category=_category_label(category, lang), eaten=eaten, tossed=tossed,
                ))
        if nudge is not None:
            lines.append("")
            lines.append(t(
                f"waste.nudge.{nudge.code}", lang,
                name=display(nudge.food) if nudge.food else "",
            ))
    if ws.window_truncated:
        lines.append(t("waste.truncated", lang))
    return "\n".join(lines)
```
