# v6.0 Phase 1 — Quota Metering Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a household-pooled quota layer that records every LLM-backed operation and can refuse it, shipping dark (recording but not enforcing) so the cost constants can be calibrated against real traffic before Phase 2 charges anyone.

**Architecture:** A new `app/billing/` package adds one orthogonal axis — _may this household spend?_ — on top of the existing `household_id` ownership axis. Enforcement is reserve-then-commit (`admit()` before work, `commit()` after) called explicitly at each handler seam, never via hidden global state. A registry-completeness test over `_MESSAGE_COMMANDS` and `EXPECTED_CALLBACK_ROUTES` makes an unclassified new command fail the suite.

**Tech Stack:** Python 3.12+, uv, SQLModel + Alembic (next revision `0017`), aiogram 3.30, pytest, ruff.

**Spec:** `docs/superpowers/specs/2026-07-28-v6.0-multi-tenant-commercialization-design.md`

**Branch:** `v6.0-multi-tenant-commercialization`

## Global Constraints

- **Session injection:** every service function takes `session: Session` as its first argument. No global state, no module-level session.
- **Explicit clock:** service functions never call `datetime.now()` internally. Callers pass `now: datetime` / `today: date`.
- **Naive UTC datetimes** in the DB. Normalize with a `_utc_naive` helper matching `app/invite_service.py:55`.
- **English strings byte-identical:** every new user-facing string goes in `app/i18n.py` `MESSAGES` with an `en` value equal to the literal it replaces. `tests/test_i18n.py` enforces placeholder parity across `en`/`zh`/`fr`/`es`.
- **Pure synchronous renderers:** renderers take `lang="en"` plus pre-resolved data. Never call the async translator from inside a renderer.
- **`Settings()` in tests** needs `# type: ignore[call-arg]` (Pylance cannot infer env-var loading).
- **Runtime config injection:** module-level constants are assigned from `Settings` in `bin/run.py`, matching the existing `cook_service_mod.COOK_COST_CEILING_MICROS = settings.cook_cost_ceiling_micros` pattern.
- **Commands:** `uv run pytest`, `uv run ruff check`, `DATABASE_PATH=./food.db uv run alembic upgrade head`.
- **`BILLING_ENABLED` defaults to `false`.** `admit()` short-circuits to _allow_ when off, but **`commit()` always records** — Phase 1's whole purpose is gathering calibration data.

## Deviations from the spec

Two intentional differences from `2026-07-28-v6.0-multi-tenant-commercialization-design.md`, both discovered while writing executable code against the real signatures:

1. **`Admission.reason` has no `"banned"` value** (spec §6.2 lists one). Ban is enforced in `resolve_authorization`, which rejects the user before any handler runs — so a banned user can never reach `admit()`, and the value would be unreachable. Ban itself lands in Phase 3.
2. **The meter's tests are split across `test_billing_meter_admit.py` and `test_billing_meter_commit.py`** rather than the single `test_billing_meter.py` named in spec §16. `admit` and `commit` are separate tasks with separate review gates; one test file per task keeps a failing task's blast radius to its own file.

from pathlib import Path

from sqlalchemy import Engine, event
from sqlmodel import Session, create_engine


def make_engine(database_path: str) -> Engine:
    Path(database_path).parent.mkdir(parents=True, exist_ok=True)
    engine = create_engine(
        f"sqlite:///{database_path}",
        echo=False,
        connect_args={"check_same_thread": False},
    )

    @event.listens_for(engine, "connect")
    def _set_sqlite_pragmas(dbapi_connection, _connection_record) -> None:
        # WAL lets the customer and operator polling loops read while the other
        # writes; the default rollback journal makes readers block writers.
        # busy_timeout replaces an instant "database is locked" with a wait.
        cursor = dbapi_connection.cursor()
        cursor.execute("PRAGMA journal_mode=WAL")
        cursor.execute("PRAGMA busy_timeout=5000")
        cursor.close()

    return engine
```

# app/billing/plans.py
"""Plan catalog: the single place every quota constant lives.

Pure data and pure functions - no session, no I/O, no clock. Recalibrating
against real usage (spec section 8.5) is a change to this module only.
"""
from __future__ import annotations

from collections.abc import Mapping
from dataclasses import dataclass
from typing import Literal

PlanTier = Literal["free", "family"]
OpClass = Literal["receipt", "cook", "plan", "edit", "chat", "search"]

PERIOD_DAYS = 30

# Weighted cost of one action, roughly proportional to real LLM spend.
# "receipt" is deliberately absent: receipts are metered on their own counter
# so the advertised "100 receipts" stays an unqualified promise.
ACTION_WEIGHTS: Mapping[OpClass, int] = {
    "chat": 1,
    "edit": 1,
    "search": 2,
    "cook": 10,
    "plan": 25,
}

# The member's /llm choice is real and now priced: a premium provider costs
# ~3x more per call, so it consumes ~3x the units.
PROVIDER_UNIT_MULTIPLIER: Mapping[str, int] = {
    "gemini": 1,
    "deepseek": 1,
    "openai": 3,
    "anthropic": 3,
}
# Fail closed - an unrecognised provider is charged the premium rate.
DEFAULT_UNIT_MULTIPLIER = 3


@dataclass(frozen=True)
class TierLimits:
    tier: PlanTier
    receipts: int
    actions: int
    seats: int
    # Real-spend guard, never displayed. See spec section 8.5.
    cost_breaker_micros: int


TIERS: Mapping[PlanTier, TierLimits] = {
    "free": TierLimits(
        tier="free", receipts=5, actions=30, seats=2,
        cost_breaker_micros=250_000,
    ),
    "family": TierLimits(
        tier="family", receipts=100, actions=300, seats=10,
        cost_breaker_micros=2_500_000,
    ),
}


def limits_for(tier: str) -> TierLimits:
    """Limits for ``tier``; an unknown tier degrades to free."""
    return TIERS.get(tier, TIERS["free"])  # type: ignore[arg-type]


def units_for(op: OpClass, provider: str) -> int:
    """Weighted action units ``op`` consumes for a member on ``provider``.

    Returns 0 for "receipt", which is metered on its own counter.
    """
    weight = ACTION_WEIGHTS.get(op, 0)
    if weight == 0:
        return 0
    return weight * PROVIDER_UNIT_MULTIPLIER.get(provider, DEFAULT_UNIT_MULTIPLIER)
```

class Subscription(SQLModel, table=True):
    """One row per household. The entitlement axis, orthogonal to ownership."""

    household_id: int = Field(foreign_key="household.id", primary_key=True)
    tier: str = "free"
    status: str = "active"
    # Telegram's subscription identity, required by refund_star_payment and
    # edit_user_star_subscription. None for free and comped households.
    telegram_charge_id: str | None = None
    # Stars refunds are per-user, so the payer must be recorded.
    payer_telegram_id: int | None = None
    period_start: datetime
    period_end: datetime
    seat_cap: int = 2
    created_at: datetime
    updated_at: datetime


class QuotaUsage(SQLModel, table=True):
    """Counters for one household in one period. Not a log."""

    household_id: int = Field(foreign_key="household.id", primary_key=True)
    period_start: datetime = Field(primary_key=True)

    receipts_used: int = 0
    # Authoritative weighted total. Stored rather than derived so retuning
    # ACTION_WEIGHTS cannot retroactively exhaust a household mid-period.
    actions_used: int = 0

    # Raw counts, for the /quota breakdown only.
    cook_used: int = 0
    plan_used: int = 0
    edit_used: int = 0
    chat_used: int = 0
    search_used: int = 0

    # Circuit-breaker input. Never displayed.
    cost_micros_used: int = 0

    # Top-ups bought during this period; they expire with it by construction.
    receipts_granted: int = 0
    actions_granted: int = 0
    cost_micros_granted: int = 0


class PaymentEvent(SQLModel, table=True):
    """Append-only ledger. telegram_charge_id is the idempotency key."""

    __table_args__ = (
        Index("ix_payment_household_created", "household_id", "created_at"),
    )

    id: int | None = Field(default=None, primary_key=True)
    household_id: int = Field(foreign_key="household.id", index=True)
    telegram_charge_id: str = Field(unique=True, index=True)
    kind: str
    sku: str
    stars: int
    payer_telegram_id: int
    payload_json: str
    created_at: datetime

```python
# app/billing/entitlement.py
"""Subscription resolution and lazy period rollover.

Rollover is lazy rather than scheduled: it is evaluated on read, inside
``admit``. There is no cron job to drift and it self-heals after downtime -
the same approach ``pending_service`` uses for its 10-minute TTLs.
"""
from __future__ import annotations

from datetime import UTC, datetime, timedelta

from sqlmodel import Session

from app.billing.plans import PERIOD_DAYS
from app.models import QuotaUsage, Subscription

PERIOD = timedelta(days=PERIOD_DAYS)


def _utc_naive(value: datetime) -> datetime:
    """Normalize to naive UTC so comparisons match SQLite-stored datetimes."""
    if value.tzinfo is not None:
        value = value.astimezone(UTC).replace(tzinfo=None)
    return value


def effective_tier(sub: Subscription) -> str:
    """The tier whose limits apply right now.

    A lapsed or cancelled subscription keeps its ``tier`` for the record but
    is served free-tier limits.
    """
    return sub.tier if sub.status == "active" else "free"


def get_or_create_subscription(
    session: Session, *, household_id: int, now: datetime
) -> Subscription:
    """Return the household's subscription, provisioning a free one if absent."""
    moment = _utc_naive(now)
    existing = session.get(Subscription, household_id)
    if existing is not None:
        return existing
    sub = Subscription(
        household_id=household_id,
        tier="free",
        status="active",
        period_start=moment,
        period_end=moment + PERIOD,
        seat_cap=2,
        created_at=moment,
        updated_at=moment,
    )
    session.add(sub)
    session.commit()
    session.refresh(sub)
    return sub


def roll_period_if_due(
    session: Session, *, sub: Subscription, now: datetime
) -> Subscription:
    """Advance the quota period so that it contains ``now``.

    Jumps straight to the containing period rather than looping, so a long
    outage costs one arithmetic step instead of one iteration per month.
    """
    moment = _utc_naive(now)
    period_end = _utc_naive(sub.period_end)
    if moment < period_end:
        return sub

    elapsed = moment - period_end
    skipped = elapsed // PERIOD
    sub.period_start = period_end + PERIOD * skipped
    sub.period_end = sub.period_start + PERIOD

    # A paid subscription whose renewal never arrived has lapsed. A comped one
    # (no charge id) has no renewal to miss and rolls forever.
    if sub.tier != "free" and sub.telegram_charge_id is not None:
        sub.status = "expired"

    sub.updated_at = moment
    session.add(sub)
    session.commit()
    session.refresh(sub)
    return sub


def get_or_create_usage(
    session: Session, *, household_id: int, period_start: datetime
) -> QuotaUsage:
    """Return the counter row for one household in one period."""
    start = _utc_naive(period_start)
    existing = session.get(QuotaUsage, (household_id, start))
    if existing is not None:
        return existing
    usage = QuotaUsage(household_id=household_id, period_start=start)
    session.add(usage)
    session.commit()
    session.refresh(usage)
    return usage
```

```python
# app/billing/meter.py
"""Quota metering: the single enforcement seam.

Reserve-then-commit. ``admit`` runs before work and may refuse; ``commit``
runs after and records what was actually spent. Both are explicit calls at
handler boundaries - deliberately not hidden inside ``llm_transport``, which
cannot refuse before the call and would need contextvars to know the
household (see spec section 6.1).
"""
from __future__ import annotations

import logging
from collections.abc import Mapping
from dataclasses import dataclass
from datetime import datetime

from sqlmodel import Session

from app.billing.entitlement import (
    effective_tier,
    get_or_create_subscription,
    get_or_create_usage,
    roll_period_if_due,
)
from app.billing.plans import OpClass, limits_for, units_for

log = logging.getLogger(__name__)

# Assigned from Settings in bin/run.py, matching the existing
# COOK_COST_CEILING_MICROS injection pattern. Off by default: phase 1 ships
# dark, recording usage without refusing it.
BILLING_ENABLED: bool = False


@dataclass(frozen=True)
class QuotaSnapshot:
    receipts_used: int
    receipts_limit: int
    actions_used: int
    actions_limit: int
    per_op: Mapping[str, int]
    period_end: datetime
    tier: str


@dataclass(frozen=True)
class Admission:
    allowed: bool
    # "ok" | "billing_disabled" | "receipts_exhausted" | "actions_exhausted"
    # | "cost_breaker"
    reason: str
    # True -> the caller must run its non-LLM fallback rather than refuse.
    degrade: bool
    snapshot: QuotaSnapshot


def _snapshot(sub, usage, limits) -> QuotaSnapshot:
    return QuotaSnapshot(
        receipts_used=usage.receipts_used,
        receipts_limit=limits.receipts + usage.receipts_granted,
        actions_used=usage.actions_used,
        actions_limit=limits.actions + usage.actions_granted,
        per_op={
            "cook": usage.cook_used,
            "plan": usage.plan_used,
            "edit": usage.edit_used,
            "chat": usage.chat_used,
            "search": usage.search_used,
        },
        period_end=sub.period_end,
        tier=effective_tier(sub),
    )


def _resolve(session: Session, *, household_id: int, now: datetime):
    """Subscription + current-period usage + applicable limits."""
    sub = get_or_create_subscription(session, household_id=household_id, now=now)
    sub = roll_period_if_due(session, sub=sub, now=now)
    usage = get_or_create_usage(
        session, household_id=household_id, period_start=sub.period_start
    )
    return sub, usage, limits_for(effective_tier(sub))


def admit(
    session: Session,
    *,
    household_id: int,
    op: OpClass,
    provider: str,
    now: datetime,
) -> Admission:
    """Decide whether ``household_id`` may perform ``op`` right now."""
    sub, usage, limits = _resolve(session, household_id=household_id, now=now)
    snapshot = _snapshot(sub, usage, limits)

    if not BILLING_ENABLED:
        return Admission(True, "billing_disabled", False, snapshot)

    # Receipts have no non-vision fallback, so they can only ever hard-block.
    degrade = op != "receipt"

    if op == "receipt":
        if usage.receipts_used >= snapshot.receipts_limit:
            return Admission(False, "receipts_exhausted", False, snapshot)
    else:
        units = units_for(op, provider)
        if usage.actions_used + units > snapshot.actions_limit:
            return Admission(False, "actions_exhausted", degrade, snapshot)

    breaker = limits.cost_breaker_micros + usage.cost_micros_granted
    if usage.cost_micros_used >= breaker:
        log.warning(
            "quota_cost_breaker_tripped",
            extra={
                "household_id": household_id,
                "op": op,
                "cost_micros_used": usage.cost_micros_used,
                "breaker": breaker,
            },
        )
        return Admission(False, "cost_breaker", degrade, snapshot)

    return Admission(True, "ok", False, snapshot)
```

_RAW_COUNTER: Mapping[str, str] = {
    "cook": "cook_used",
    "plan": "plan_used",
    "edit": "edit_used",
    "chat": "chat_used",
    "search": "search_used",

def commit(
    session: Session,
    *,
    household_id: int,
    op: OpClass,
    provider: str,
    cost_micros: int | None,
    now: datetime,
) -> None:
    """Record one completed operation and what it actually cost.

    Always records, even when ``BILLING_ENABLED`` is False: phase 1 ships dark
    precisely to gather the data the constants are calibrated against.

    Call this even when the operation failed partway - spend is spend.
    """
    _sub, usage, _limits = _resolve(session, household_id=household_id, now=now)

    if op == "receipt":
        usage.receipts_used += 1
    else:
        counter = _RAW_COUNTER.get(op)
        if counter is not None:
            setattr(usage, counter, getattr(usage, counter) + 1)
        usage.actions_used += units_for(op, provider)

    usage.cost_micros_used += cost_micros or 0
    session.add(usage)
    session.commit()

    log.info(
        "quota_commit",
        extra={
            "household_id": household_id,
            "op": op,
            "provider": provider,
            "cost_micros": cost_micros or 0,
            "actions_used": usage.actions_used,
            "receipts_used": usage.receipts_used,
        },
    )

# app/billing/render.py
"""Pure synchronous rendering of the quota card.

Takes a resolved snapshot and a language; performs no I/O and never calls the
async translator (v4.1 two-phase render convention).
"""
from __future__ import annotations

from app.billing.meter import QuotaSnapshot
from app.billing.plans import ACTION_WEIGHTS
from app.i18n import t

_BREAKDOWN_ORDER = ("cook", "plan", "edit", "chat", "search")


def render_quota(
    snapshot: QuotaSnapshot, *, days_left: int, lang: str = "en"
) -> str:
    lines = [
        t("quota.title", lang, n=days_left),
        "",
        t("quota.receipts", lang,
          used=snapshot.receipts_used, limit=snapshot.receipts_limit),
        t("quota.actions", lang,
          used=snapshot.actions_used, limit=snapshot.actions_limit),
    ]

    for op in _BREAKDOWN_ORDER:
        count = snapshot.per_op.get(op, 0)
        if count == 0:
            continue
        weight = ACTION_WEIGHTS[op]  # type: ignore[index]
        label = t(f"quota.op.{op}", lang)
        lines.append(f"    {label} {count} x {weight} = {count * weight}")

    if snapshot.tier == "free":
        lines.extend(["", t("quota.upsell", lang)])

    return "\n".join(lines)
```

# app/handlers/billing.py
"""Customer-facing billing commands. Phase 1 ships /quota only."""
from __future__ import annotations

import logging
from collections.abc import Callable

from app import handler_support
from app.billing.entitlement import get_or_create_subscription, roll_period_if_due
from app.billing.meter import admit
from app.billing.render import render_quota
from app.handler_support import NowProvider
from app.models import User

log = logging.getLogger(__name__)

_request = handler_support.request
_noop_user_created = handler_support.noop_user_created


async def handle_quota(
    msg,
    *,
    session_factory,
    now_provider: NowProvider,
    on_user_created: Callable[[User], None] = _noop_user_created,
):
    async with _request(
        msg, session_factory=session_factory, on_user_created=on_user_created
    ) as ctx:
        if ctx is None:
            return
        session, user = ctx.session, ctx.user
        now = now_provider(user.tz)
        try:
            sub = get_or_create_subscription(
                session, household_id=user.household_id, now=now
            )
            sub = roll_period_if_due(session, sub=sub, now=now)
            decision = admit(
                session,
                household_id=user.household_id,
                op="chat",
                provider=user.llm_provider,
                now=now,
            )
            days_left = max(0, (sub.period_end - now.replace(tzinfo=None)).days)
            text = render_quota(
                decision.snapshot, days_left=days_left, lang=user.lang
            )
        except Exception as exc:  # noqa: BLE001 - /quota must never crash the bot
            log.warning(
                "quota_render_failed",
                extra={"user_id": user.telegram_id,
                       "error_class": type(exc).__name__},
            )
            await msg.answer("couldn't load your quota right now")
            return
        await msg.answer(text)


COMMANDS = (
    ("quota", handle_quota,
     ("session_factory", "now_provider", "on_user_created")),
)
```

> Note the broad `except Exception` around the service calls. Per the project's
> recorded convention, `bot.py` handlers wrap service calls in a catch-all, not
> only the expected exception type.
