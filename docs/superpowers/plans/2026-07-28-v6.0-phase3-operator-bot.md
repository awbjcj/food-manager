# v6.0 Phase 3 — Operator Bot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the operator a private Telegram surface for support and control — look up a household, comp quota, refund a payment, ban an abuser, read revenue, and reconcile the local ledger against Telegram's own record.

**Architecture:** A second `Bot` + `Dispatcher` on its own token, running in the **same process** as the customer bot under `asyncio.gather`, each polling loop wrapped in its own `run_with_restart`. Same-process is forced, not chosen: `app/db.py` opens a file-backed SQLite engine and a Railway volume mounts to exactly one service, so two containers cannot share the database. The operator bot shares no handler code with the customer bot, so no customer command can reach an operator action.

**Tech Stack:** Python 3.12+, uv, aiogram 3.30, SQLModel, pytest, ruff.

**Spec:** `docs/superpowers/specs/2026-07-28-v6.0-multi-tenant-commercialization-design.md` §11

**Depends on:** Phase 1 and Phase 2 complete and merged.

## Global Constraints

- Everything in Phase 1's Global Constraints still applies.
- **Operator strings are English-only** and stay out of `app/i18n.py`. The operator is one person and the surface is internal; adding them to the catalog would force four translations of text nobody else reads.
- **Authorization is a membership test against `Settings.operator_ids`** (added in Phase 1 Task 1), checked at the top of every operator handler. There is no fallback, no bootstrap path, and no self-service.
- **The operator bot is optional.** When `OPERATOR_BOT_TOKEN` is unset the second dispatcher is never constructed and the process runs exactly as it does today.
- All money-mutating commands (`/grant`, `/refund`) write a `PaymentEvent` row so `/revenue` and `/reconcile` stay truthful.

### Audit corrections

- `/grant` requires an existing household, rejects negative values and zero/zero
  grants, and derives breaker headroom from the quantities granted.
- `/refund` checks `refund:<charge_id>` before calling Telegram. The confirmed
  refund row and downgrade commit together.
- `/reconcile` paginates until a short page, compares amounts, and reports both
  remote-only and local-only purchases. Truncation must never report no drift.
- Operator arguments are boundary-validated before service calls.

```python
# app/operator/auth.py
"""Operator identity check.

A plain membership test against a configured id set. There is no bootstrap
path and no self-service: the only way to become an operator is a deploy.
"""
from __future__ import annotations

import logging

log = logging.getLogger(__name__)

# Assigned from Settings.operator_ids in bin/run.py. Empty means nobody -
# failing closed, so a misconfiguration locks the operator out rather than
# letting everyone in.
OPERATOR_IDS: frozenset[int] = frozenset()


def is_operator(telegram_id: int) -> bool:
    return telegram_id in OPERATOR_IDS


async def require_operator(msg) -> bool:
    """Gate an operator handler. Returns False if the sender is not an operator.

    Deliberately silent on rejection: replying would confirm to a stranger
    that this bot exists and does something privileged.
    """
    sender = getattr(msg.from_user, "id", None)
    if sender is not None and is_operator(sender):
        return True
    log.warning("operator_access_denied", extra={"telegram_id": sender})
    return False
```

```python
# app/operator/queries.py
"""Read-only projections for the operator surface."""
from __future__ import annotations

from dataclasses import dataclass
from datetime import datetime

from sqlmodel import Session, select

from app.billing.entitlement import (
    effective_tier,
    get_or_create_subscription,
    get_or_create_usage,
    roll_period_if_due,
)
from app.models import User


@dataclass(frozen=True)
class HouseholdReport:
    household_id: int
    tier: str
    status: str
    seat_cap: int
    member_count: int
    banned_members: list[int]
    receipts_used: int
    actions_used: int
    cost_micros_used: int
    period_start: datetime
    period_end: datetime


def describe_household(
    session: Session, *, telegram_id: int, now: datetime
) -> HouseholdReport | None:
    """Everything the operator needs about the household ``telegram_id`` is in."""
    user = session.get(User, telegram_id)
    if user is None:
        return None

    sub = get_or_create_subscription(
        session, household_id=user.household_id, now=now
    )
    sub = roll_period_if_due(session, sub=sub, now=now)
    usage = get_or_create_usage(
        session, household_id=user.household_id, period_start=sub.period_start
    )
    members = session.exec(
        select(User).where(User.household_id == user.household_id)
    ).all()

    return HouseholdReport(
        household_id=user.household_id,
        tier=effective_tier(sub),
        status=sub.status,
        seat_cap=sub.seat_cap,
        member_count=len(members),
        banned_members=sorted(m.telegram_id for m in members if m.banned),
        receipts_used=usage.receipts_used,
        actions_used=usage.actions_used,
        cost_micros_used=usage.cost_micros_used,
        period_start=sub.period_start,
        period_end=sub.period_end,
    )
```

```python
# app/operator/bot.py
"""The operator bot: a second Dispatcher on its own token.

Shares no handler code with the customer bot, so there is no code path by which
a customer command could reach an operator action. Strings are English-only by
design (spec section 15).
"""
from __future__ import annotations

import logging

from aiogram import Dispatcher
from aiogram.filters import Command

from app.operator.auth import require_operator
from app.operator.queries import describe_household

log = logging.getLogger(__name__)


def _int_arg(text: str | None) -> int | None:
    """Second whitespace-separated token as an int, or None."""
    parts = (text or "").split()
    if len(parts) < 2:
        return None
    try:
        return int(parts[1])
    except ValueError:
        return None


async def handle_whois(msg, *, session_factory, now_provider):
    if not await require_operator(msg):
        return
    telegram_id = _int_arg(msg.text)
    if telegram_id is None:
        await msg.answer("usage: /whois <telegram_id>")
        return
    try:
        with session_factory() as session:
            report = describe_household(
                session, telegram_id=telegram_id, now=now_provider("UTC")
            )
    except Exception as exc:  # noqa: BLE001 - operator tools must not crash the loop
        log.warning("whois_failed", extra={"error_class": type(exc).__name__})
        await msg.answer("lookup failed")
        return

    if report is None:
        await msg.answer(f"no user {telegram_id}")
        return

    await msg.answer(
        f"user {telegram_id}\n"
        f"household {report.household_id}\n"
        f"tier {report.tier} ({report.status})\n"
        f"members {report.member_count}/{report.seat_cap}\n"
        f"banned {report.banned_members or 'none'}\n"
        f"receipts {report.receipts_used}\n"
        f"actions {report.actions_used}\n"
        f"spend {report.cost_micros_used} micros\n"
        f"period ends {report.period_end:%Y-%m-%d}"
    )


OPERATOR_COMMANDS: tuple[tuple[str, object, tuple[str, ...]], ...] = (
    ("whois", handle_whois, ("session_factory", "now_provider")),
)


def build_operator_dispatcher(
    *, session_factory, now_provider, payments=None
) -> Dispatcher:
    dispatcher = Dispatcher()
    deps = {
        "session_factory": session_factory,
        "now_provider": now_provider,
        "payments": payments,
    }

    def _bind(handler, *dep_names):
        kwargs = {name: deps[name] for name in dep_names}

        async def _registered(event):
            await handler(event, **kwargs)

        return _registered

    for name, handler, dep_names in OPERATOR_COMMANDS:
        dispatcher.message.register(_bind(handler, *dep_names), Command(name))

    return dispatcher
```

```python
import uuid

from app.billing.entitlement import apply_topup
from app.billing.ledger import record_payment
from app.billing.plans import Sku

# A comped grant raises the breaker by the same headroom a paid top-up buys,
# so granted quota is actually servable rather than blocked by the cost guard.
GRANT_COST_MICROS = 1_250_000


async def handle_grant(msg, *, session_factory, now_provider):
    if not await require_operator(msg):
        return
    parts = (msg.text or "").split()
    try:
        household_id, receipts, actions = (
            int(parts[1]), int(parts[2]), int(parts[3])
        )
    except (IndexError, ValueError):
        await msg.answer("usage: /grant <household_id> <receipts> <actions>")
        return

    grant = Sku(
        code="operator_grant",
        title="Operator grant",
        description="Comped quota",
        stars=0,
        kind="grant",
        grants_receipts=receipts,
        grants_actions=actions,
        grants_cost_micros=GRANT_COST_MICROS,
    )
    now = now_provider("UTC")
    try:
        with session_factory() as session:
            # A synthetic charge id keeps the unique index satisfied and makes
            # each grant a distinct, auditable ledger row.
            record_payment(
                session,
                household_id=household_id,
                charge_id=f"grant:{uuid.uuid4()}",
                kind="grant",
                sku=grant.code,
                stars=0,
                payer_telegram_id=msg.from_user.id,
                payload_json=f'{{"receipts":{receipts},"actions":{actions}}}',
                now=now,
            )
            apply_topup(session, household_id=household_id, sku=grant, now=now)
    except Exception as exc:  # noqa: BLE001
        log.warning("grant_failed", extra={"error_class": type(exc).__name__})
        await msg.answer("grant failed")
        return

    await msg.answer(
        f"granted household {household_id}: +{receipts} receipts, +{actions} actions"
    )
```

```python
from app.billing.entitlement import apply_refund
from app.billing.ledger import find_event


async def handle_refund(msg, *, session_factory, now_provider, payments=None):
    if not await require_operator(msg):
        return
    parts = (msg.text or "").split()
    if len(parts) < 2:
        await msg.answer("usage: /refund <telegram_payment_charge_id>")
        return
    charge_id = parts[1]
    if payments is None:
        await msg.answer("payments are not configured")
        return

    now = now_provider("UTC")
    try:
        with session_factory() as session:
            original = find_event(session, charge_id=charge_id)
            if original is None:
                await msg.answer(f"unknown charge {charge_id}")
                return
            household_id = original.household_id
            payer = original.payer_telegram_id

        refunded = await payments.refund(user_id=payer, charge_id=charge_id)
        if not refunded:
            # Entitlement is never taken away unless the money actually moved.
            await msg.answer("the rail refused the refund; nothing changed")
            return

        with session_factory() as session:
            record_payment(
                session,
                household_id=household_id,
                charge_id=f"refund:{charge_id}",
                kind="refund",
                sku=original.sku,
                stars=original.stars,
                payer_telegram_id=payer,
                payload_json="{}",
                now=now,
            )
            apply_refund(session, household_id=household_id, now=now)
    except Exception as exc:  # noqa: BLE001
        log.warning("refund_failed", extra={"error_class": type(exc).__name__})
        await msg.answer("refund failed")
        return

    await msg.answer(f"refunded {charge_id}; household {household_id} downgraded")
```

```python
from sqlmodel import select

from app.billing.ledger import revenue_stars
from app.models import PaymentEvent


async def handle_revenue(msg, *, session_factory, now_provider):
    if not await require_operator(msg):
        return
    days = _int_arg(msg.text) or 30
    now = now_provider("UTC")
    try:
        with session_factory() as session:
            total = revenue_stars(session, since=now - timedelta(days=days))
    except Exception as exc:  # noqa: BLE001
        log.warning("revenue_failed", extra={"error_class": type(exc).__name__})
        await msg.answer("revenue query failed")
        return
    await msg.answer(f"last {days}d: {total} Stars")


async def handle_reconcile(msg, *, session_factory, payments=None):
    """Diff the local ledger against the rail's own record.

    Drift matters: the ledger is what /revenue and /refund trust, so a charge
    Telegram knows about but the bot does not may mean money moved without
    entitlement being granted.
    """
    if not await require_operator(msg):
        return
    if payments is None:
        await msg.answer("payments are not configured")
        return
    try:
        remote = await payments.list_transactions(offset=0, limit=100)
        with session_factory() as session:
            local = {
                e.telegram_charge_id
                for e in session.exec(select(PaymentEvent)).all()
            }
    except Exception as exc:  # noqa: BLE001
        log.warning("reconcile_failed", extra={"error_class": type(exc).__name__})
        await msg.answer("reconcile failed")
        return

    missing = sorted({row.charge_id for row in remote} - local)
    if not missing:
        await msg.answer(f"no drift ({len(remote)} remote, {len(local)} local)")
        return
    await msg.answer("missing locally:\n" + "\n".join(missing))
```
